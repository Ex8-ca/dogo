# Dogo 0.1.0-alpha.1

First Dogo testing prerelease. Based on Lawnchair/Launcher3; see LICENSE and
NOTICE. This is not a stable release or an official Lawnchair build.

## Included

- Dogo launcher branding, wallpaper-aware colours and organised Dogo Options.
- Agent/chat and voice foundations, Dogo Ring and plugin support.
- Opt-in notification-assistant foundations and enforced tools-off routing for
  supported untrusted-text analysis. Configure and test your own endpoint.
- Text-file widget tiles: validation, live change list, requested-grid diagram,
  and add/move/resize/remove through the launcher database. Only tracked tile
  widgets are managed; other home-screen items are treated as occupied.

## Tested

- 499 unit tests, zero failures/errors, two intentionally skipped.
- Formatting gate and debug APK build.
- Pixel 2 XL running LineageOS 22.2: real widgets added, moved, resized, removed
  and restored through the debug Undo path; minimum-size refusal and provider
  setup exercised. Preview and Dismiss left launcher data and bindings unchanged.
- Approval card, refusal/removal list and requested diagram inspected on-device.

## Download and installation

Download `Dogo-0.1.0-alpha.1-debug.apk` and optionally verify it against
`SHA256SUMS`. It targets Android 8.0/API 26 or newer, but device testing has only
been done on the Pixel above. Other devices and Android versions are unverified.

This APK is DEBUGGABLE and signed with the local Android debug certificate,
NOT a production Dogo signing key. Package: `app.dogo.launcher.debug`. It updates
compatible local debug builds with the same signing certificate. A different
certificate will cause Android to refuse the update: do not uninstall your
existing launcher to work around this without exporting/backing up your setup.
Future production builds may use a separate package and signing identity.

Android may require explicitly allowing installation from the download source.
After installation choose Dogo as Home if desired. AI services need your own
credentials and configuration; no account credentials are bundled in the APK.
Keep another launcher installed so you can switch back.

The debug APK includes adb-only test receivers requiring Android's DUMP
permission. These can mutate test layouts when deliberately called via adb.
Do not treat this artifact as a hardened production distribution.

## Known limitations / held work

- The diagram is the REQUESTED layout, not the accepted plan or rendered widget
  content. Grid-change counts/refusals are provisional until the grid reloads.
- Apply rechecks current state; preview is not a transaction or a locked plan.
- Undo currently exists through the adb test path, not a production one-tap UI.
- Tile style keys parse but do not affect live gaps, rounding, borders or blur.
- Automatic home screenshots, local look checks and opt-in model vision advice
  are not implemented. No real-agent layout-design end-to-end run is claimed.
- Widget bind/setup may require a tap. Blank content is not proof of failure.
- Phone-use automation is experimental, not a complete agent-control workflow.
  Accessibility stays off by default. Do not grant root prompts blindly.
- Full notification-to-dogosafe phone testing remains open; a prompt is not a
  substitute for an actually tools-off server route.

## Rollout and withdrawal

This is an opt-in tester download only: no app-store rollout or automatic
updates. Do not promote to stable until missing acceptance checks are done.

If the alpha fails to launch twice consecutively or any tester reports unintended
home-item mutation, stop distribution and switch Home to another installed
launcher. Marc/operator can withdraw the published assets with:

```sh
gh release edit v0.1.0-alpha.1 --repo Ex8-ca/dogo --draft=true
```

Verify withdrawal with `gh release view v0.1.0-alpha.1 --repo Ex8-ca/dogo
--json isDraft`. Withdrawal cannot undo downloads or layout/database changes.
There is no previous public APK release to promise as a rollback. Preserve the
existing app/data; an APK downgrade can be refused and is not a data restore.
