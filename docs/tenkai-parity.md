# Tenkai feature list, mapped to Dogo

Tenkai is a closed, paid launcher. This is the list of features from its
pricing page, and where each one stands in Dogo. "Lawnchair" means the feature
already comes with the launcher Dogo is built on (Dogo Settings), so Dogo
didn't need to build it; the agent can still set many of them for you.

| Tenkai feature | In Dogo | Where |
|---|---|---|
| Gesture pie menus, nested sub-pies | Yes | Dogo Ring (touch and hold the home screen) |
| Up to 5 levels / unlimited parallel pies | Partly | Ring groups nest; one ring at a time |
| Premium themes: Radar, Electric, Fire, Magic, Dark | Yes | Ring styles Radar, Electric, Fire, Glow (Magic), Minimal (Dark) |
| 18 curated presets | Partly | Ask Dogo for a layout, or apply an Omarchy theme |
| Searchable A–Z app drawer | Lawnchair | App drawer |
| Multiple home spaces | Lawnchair | Home screen pages |
| Android widgets | Yes | Add yourself, or ask Dogo (`add_widget`) |
| Classic dock | Lawnchair | Dock; Dogo can choose its apps (`set_dock`) |
| Notification badges | Lawnchair | Settings > General > Notification dots; counts via `style_home` |
| Hidden apps | Yes | Lawnchair, or ask Dogo (`hide_app`) |
| Custom icon packs | Lawnchair | Settings > General > Icon pack; Dogo can switch it (`style_home`) |
| App contextual menus | Lawnchair | Long-press an app |
| Multi-finger gestures | Lawnchair | Settings > Gestures (two-finger swipes, double tap) |
| Backup / restore | Lawnchair | Settings > Backup and restore |
| No ads, no tracking, on-device | Yes | On-device agent by default; Google-free |
| Live Capsules | Partly | "At a Glance" line (date, battery, music, torch) |
| Catch-Up Inbox hub | Not yet | Planned as a plugin |
| HTTP queries (weather, IP, bitcoin), custom REST + JSONPath | Not yet | Planned as a plugin; Hermes can already fetch these when you ask |
| RSS/Atom feeds, FreshRSS sync | Not yet | Planned as a plugin (or a Hermes skill) |
| Automations (show a widget when…) | Not yet | Planned |
| Multi-touch zones, dynamic docks | Not yet | |
| Floating virtual spaces | Not yet | Freeform windows work on this phone; see the tiling notes |

Dogo has things Tenkai doesn't: an agent that changes the phone when you ask
(typed, by voice, or from a photo of another phone), plugins, Omarchy themes,
and least-access system changes.
